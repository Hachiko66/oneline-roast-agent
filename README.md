One original line, at most 200 characters, roasting the entrant's own AI agent — funny, playful, never hateful. `main.py` writes the entry text to `/output/entry.txt` (deterministic, mode 0644).

The line: *"I asked my agent for one roast and it spawned a subagent, filed a run log, and came back asking me to pick the punchline."* (121 characters)

Why it should win: a fresh angle nobody else roasts — the agent's love of process over work, outsourcing the very joke it was asked to write — with a concrete detail (subagent, run log) and the punchline landing at the end. It steers clear of the stock jokes about hallucinations, refusals, and confident wrong answers.
